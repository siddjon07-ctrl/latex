\section{What is LaTeX?}

LaTeX is a document preparation system used to create
professional documents, especially those containing
mathematical equations.

\section{Why Use LaTeX?}

\begin{itemize}
    \item Professional document formatting
    \item Easy mathematical typesetting
    \item Automatic numbering of sections and equations
\end{itemize}
