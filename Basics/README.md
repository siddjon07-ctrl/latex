
# Module 01 – LaTeX Basics

This module covers the fundamentals of LaTeX document preparation.

## Files

- `introduction.tex` – Basic document structure, title, author, date and sections.
- `formatting.tex` – Text formatting, subsections, ordered and unordered lists.

## Concepts Covered

- Document classes and environments
- Title and author information
- Sections and subsections
- Text formatting
- Ordered and unordered lists

## Compilation

Both files can be compiled using Overleaf.
