# LaTeX Journey

A collection of LaTeX notes, examples, presentations, and documentation created while learning LaTeX and related tools.

This repository documents my learning journey through LaTeX, starting with the fundamentals and progressing to mathematical typesetting, tables, figures, document formatting, presentations, and documentation tools.

## About This Repository

The purpose of this repository is to:

- Practice LaTeX concepts through practical examples.
- Maintain organized notes from academic lectures.
- Understand document preparation and presentation design.
- Keep examples and compiled PDFs in one place.
- Build familiarity with professional documentation tools.

## Modules

### 01 – Basics
Introduction to LaTeX and basic document formatting.

Topics:
- Document structure
- Document classes
- Title, author and date
- Sections and subsections
- Text formatting
- Itemized and numbered lists

### 02 – Mathematics
Mathematical typesetting and equation formatting.

Topics:
- Inline and display mathematics
- Mathematical symbols and Greek letters
- Fractions, roots and operators
- Superscripts and subscripts
- Mathematical fonts
- Equation and align environments
- Arrays and matrices

### 03 – Tables, Colors and Figures
Creating structured and visually formatted documents.

Topics:
- Tables and tabular environments
- Rows and columns
- Multirow and multicolumn
- Captions, labels and references
- Text and background colors
- Including and resizing images
- Trimming and rotating figures
- Multiple images using minipage

### 04 – Document and Page Styles
Customizing document layout and appearance.

Topics:
- Document classes and class options
- Title pages and abstracts
- Page margins and page styles
- Headers and footers
- Paragraph and page spacing
- Section heading customization
- Page background colors
- Boxes and page breaks
- Bibliography and BibTeX

### 05 – Beamer Presentations
Creating presentations using LaTeX Beamer.

Includes:
- Basic Beamer presentation
- Presentation source files and compiled PDF

### 06 – Documentation Tools
Learning documentation tools and their use in software development.

### 07 – Git and GitHub
Version control and project collaboration.

Topics:
- Git fundamentals and configuration
- Repository initialization
- Staging and committing
- Git history and diff
- File management and undoing changes
- Branches and merging
- GitHub repositories and remote connections
- Push, pull and fetch
- Pull requests and collaboration
- Tags and releases
- `.gitignore`

## Tools Used

- **LaTeX:** Document preparation and mathematical typesetting.
- **Overleaf:** Online LaTeX editor and compiler.
- **Visual Studio Code:** Local editing and project management.
- **Git:** Version control.
- **GitHub:** Repository hosting and project sharing.

## How to Use This Repository

1. Open the module you want to explore.
2. Read its README file for an overview of the topics.
3. Open the `.tex` source files to study the examples.
4. View the corresponding PDF files to see the compiled output.
5. Open the source files in Overleaf or compile them using a local LaTeX distribution.

## Learning Approach

Each module focuses on practical examples and concepts covered during learning. The repository is organized module-wise to make the material easy to navigate, revise, and extend.
