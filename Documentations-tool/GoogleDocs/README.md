# Google Docs – Basic Introduction

## 1. What is Google Docs?

Google Docs is a cloud-based word processor provided by Google. It allows users to create, edit, format and share documents online.

## 2. Why Do We Use Google Docs?

- Create and edit documents online.
- Collaborate with multiple people in real time.
- Share documents with different access permissions.
- Automatically save changes.
- Access documents from different devices.

## 3. Important Features

| Feature | Purpose |
|---|---|
| Headings and Styles | Organize document content into sections. |
| Tables | Present information in a structured format. |
| Lists | Organize information using bullets and numbers. |
| Comments | Give feedback on document content. |
| Suggestions | Propose edits without directly changing the original text. |
| Version History | View and restore previous versions. |
| Sharing | Give others view, comment or edit access. |
| Citations | Add references and generate a bibliography. |
| Export | Download documents in formats such as PDF and DOCX. |

## 4. Collaboration

Google Docs supports real-time collaboration.

Multiple users can work on the same document, see changes and communicate through comments and suggestions.

## 5. Version History

Version history allows users to:
- View earlier versions of a document.
- Identify changes made over time.
- Restore a previous version.
- Name important versions.

## 6. Sharing Permissions

Documents can be shared with different permissions:

- **Viewer:** Can only view the document.
- **Commenter:** Can view and add comments.
- **Editor:** Can view and modify the document.
