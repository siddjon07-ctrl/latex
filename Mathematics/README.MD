
# Module 02 – Mathematics in LaTeX

This module demonstrates mathematical typesetting using LaTeX.

## Files

- `mathematics.tex` – LaTeX source code demonstrating mathematical notation and environments.
- `mathematics.pdf` – Compiled output of the source document.

## Concepts Covered

- Inline and display mathematics
- Mathematical fonts and display styles
- Superscripts and subscripts
- Greek letters and mathematical symbols
- Fractions, roots, summations, products and integrals
- Numbered and aligned equations
- Arrays and matrices
- Ordered, unordered and description lists

## Packages Used

- `amsmath` – Mathematical environments and equation formatting.
- `amssymb` – Additional mathematical symbols.

## Compilation

The source file can be compiled using Overleaf.
