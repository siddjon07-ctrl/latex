# Module 05 – Beamer Presentations

This module demonstrates the basics of creating presentations using LaTeX Beamer.

## Files

- `basic-presentation.tex` – LaTeX source code for the presentation.
- `basic-presentation.pdf` – Compiled presentation.

## Topics Covered

- Introduction to Beamer
- Beamer document class
- Title slide using `\titlepage`
- Slides using the `frame` environment
- Slide titles
- Bullet points and nested lists
- Mathematical equations
- Vertical spacing
- Concluding slide

## Compilation

The presentation was created and compiled using Overleaf.

## Theme

The presentation uses a customized Beamer theme inspired by the lecture slides taught at MNIT Jaipur.
