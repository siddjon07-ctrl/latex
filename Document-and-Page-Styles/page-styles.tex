\section{Page Styles}

The \texttt{\textbackslash pagestyle} command
controls the appearance of headers and footers.

Some predefined page styles are:

\begin{itemize}
    \item \textbf{plain}: Displays the page number
    at the bottom of the page.

    \item \textbf{empty}: Removes headers and footers.

    \item \textbf{headings}: Displays section or
    chapter headings in the header.
\end{itemize}

\section{Customizing Page Margins}

The geometry package allows us to customize
the margins of a document.

For example, the current document uses:

\begin{verbatim}
\usepackage{geometry}
\geometry{
    left=2.5cm,
    right=2.5cm,
    top=2.5cm,
    bottom=2.5cm
}
\end{verbatim}

\section{Custom Headers and Footers}

The fancyhdr package allows us to customize
the header and footer.

\begin{itemize}
    \item \texttt{\textbackslash fancyhf\{\}} clears
    existing header and footer settings.

    \item \texttt{\textbackslash fancyhead[L]}
    sets the left header.

    \item \texttt{\textbackslash fancyhead[C]}
    sets the center header.

    \item \texttt{\textbackslash fancyhead[R]}
    sets the right header.

    \item \texttt{\textbackslash fancyfoot[C]}
    sets the center footer.
\end{itemize}
