# Module 04: Document and Page Styles

This module explores document structure, page layout, document customization, text boxes, and bibliography management in LaTeX.

## Files

| File | Description |
|---|---|
| `document-structure.tex` | Document classes, title formatting and abstract |
| `document-structure.pdf` | Compiled document structure |
| `page-styles.tex` | Page styles, margins, headers, footers, spacing and text boxes |
| `page-styles.pdf` | Compiled page styles |
| `refs.bib` | BibTeX bibliography database |

## Topics Covered

### 1. Document Structure
- Document classes: `article`, `report`, `book`
- Font size and paper size options
- Title, author and date
- `\maketitle`
- Title customization
- Abstract environment
- Sections and subsections

### 2. Page Styles and Layout
- `\pagestyle`
- Predefined styles: `plain`, `empty`, `headings`
- Page margins using `geometry`
- Headers and footers using `fancyhdr`
- Paragraph indentation and spacing
- Horizontal and vertical spacing
- Page breaks using `\newpage` and `\pagebreak`

### 3. Document Customization
- Section heading customization using `sectsty`
- Page background color using `xcolor`
- List customization using `enumitem`

### 4. Boxes and Text Positioning
- `\mbox`
- `samepage` environment
- `\parbox`
- `\raisebox`
- Manual line breaks

### 5. Bibliography and BibTeX
- Creating a `.bib` file
- BibTeX entries
- `\cite`
- `\bibliographystyle`
- `\bibliography`

## Packages Used
- `geometry`
- `fancyhdr`
- `xcolor`
- `sectsty`
- `enumitem`

## Compilation

Compile the `.tex` files using Overleaf or a LaTeX editor. The bibliography uses the separate `refs.bib` file.
