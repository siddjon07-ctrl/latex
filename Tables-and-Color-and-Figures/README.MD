# Module 03: Tables, Colors and Figures

This module covers the creation and formatting of tables, the use of colors, and inserting and arranging images in LaTeX.

## Files

| File | Description |
|---|---|
| `tables_colors.tex` | Tables, advanced tables, text colors, mathematical colors and colored tables |
| `figures.tex` | Image insertion, resizing, trimming, rotation and minipage |
| `mnit-logo.png` | Image used for practical examples |

## Topics Covered

### 1. Tables
- `tabular` environment
- Table alignment and borders
- `\hline` and `\cline`
- `\multicolumn`
- `\multirow`
- Table captions and labels
- Table positioning

### 2. Colors
- `xcolor` package
- Predefined colors
- Custom colors using RGB and HTML
- `\textcolor`
- Coloring mathematical expressions
- Colored table rows using `\rowcolor`
- Colored cells using `\cellcolor`

### 3. Figures
- `graphicx` package
- Inserting images using `\includegraphics`
- Resizing images
- Trimming images using `trim` and `clip`
- Rotating images using `angle`
- Image captions and references
- `minipage` environment for side-by-side layouts

## Packages Used
- `multirow`
- `xcolor`
- `graphicx`
- `amsmath`

## Compilation

Compile each `.tex` file separately using Overleaf or a LaTeX editor.
